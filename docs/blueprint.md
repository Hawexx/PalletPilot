# **App Name**: PalletPilot

## Core Features:

- Order Configuration: A panel to configure and adjust order parameters dynamically.
- Pallet Visualization: A layer-by-layer view of the pallet composition, displaying box positions.
- Equipment Status: Visual representation of AS/RS, robot arms, and conveyor status.
- Mix Pallet Algorithm Preview: Preview of the pallet building decisions based on product grouping and weight optimization, making it easy to evaluate how well the tool will perform.
- Stability Score Indicator: Real-time style display of the current pallet's stability score (mock data).
- Load Balance Visualization: Graphical representation of the pallet's load balance, updated dynamically (mock data).
- Product Grouping Indicators: Visual cues to show how products are grouped on each pallet layer.

## Style Guidelines:

- Primary color: Deep navy blue (#2E3A59) for a professional and reliable feel.
- Background color: Light gray (#F0F4F8) for a clean, modern interface.
- Accent color: Electric blue (#7DF9FF) for highlighting key elements and interactive components.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern look, suitable for data-heavy dashboards.
- Clear, minimalist icons representing pallets, boxes, robots, and conveyors.
- A modern, industrial-grade layout with a clear visual hierarchy.
- Smooth micro-animations and transitions to enhance user experience.
